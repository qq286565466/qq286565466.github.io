# 星局 V0.39

一个无需构建工具的静态浏览器卡牌游戏：1 名真人玩家对战 3 名 AI。项目可以直接通过静态文件服务器运行。

## 当前版本

- **游戏版本：V0.39**
- 从 V0.32 起取消旧的双版本显示，标题、界面、图鉴和存档统一使用同一个游戏版本号。
- 版本唯一来源：`assets/js/version.js`。后续每次正式更新都需要递增这里的版本号。

## V0.39 更新：AI 托管

- 对局顶部新增【AI托管】开关；开启后由 AI 自动操作真人座位，关闭后恢复手动操作。
- 托管复用现有 AI 的出牌、目标选择、弃牌和技能决策能力，但不会把真人玩家改成 AI 身份，胜负与星石结算保持原逻辑。
- 托管覆盖正常回合和额外回合，并自动处理充能、骰命、占卜、结界、污染、牌匠、截胡、共振、强制清仓等需要选择的流程。
- 在真人出牌阶段开启托管会立即接管当前回合；关闭时会取消尚未执行的自动出牌计时。
- 托管状态只属于当前对局，不写入存档，新开一局默认关闭。
- `assets/js/config.js` 新增 `trusteeThinkMs`，可独立调整真人托管的自动操作节奏。

### 托管参数修改入口

```js
match: {
  aiThinkMs: 2000,      // 三名 AI 对手的思考时间
  trusteeThinkMs: 900   // 真人开启托管后的思考时间
}
```

## V0.38 更新：《星局》品牌与图标系统

- 游戏正式名称由“欢乐牌局”统一为 **《星局》**，浏览器标题、启动页、大厅和存档提示同步更新。
- 新增 `assets/icons/`，集中存放网页优化后的品牌与功能图标。
- 大厅品牌区接入《星局》主徽章；浏览器 favicon 使用同一品牌资源。
- 新手场、普通场、高级场分别使用新芽、梅花星盘、王冠星耀三枚独立徽章。
- 【更多功能】与【玩法规则】入口接入同风格玉绿金色图标。
- 新图标加入启动预加载队列，避免首次进入大厅时出现图片闪烁；游戏规则和存档结构不变。

### 图标修改入口

所有大厅图标都在 `assets/icons/`。保持文件名不变直接替换图片即可更新视觉，不需要修改游戏逻辑。

## V0.37 更新：快速对局基础配置

- 新增 `assets/js/config.js`，集中维护最常改的基础对局参数。
- 起手牌数、AI 思考时间、场地触发间隔、默认星石以及三档房间参数改为配置驱动。
- 大厅底注/入场门槛、规则页数字、场地轮次提示都会自动跟随配置变化。
- 当前默认数值保持原玩法：起手 2 张、AI 2 秒、每 5 轮抽场地、默认 2000 星石。
- 胜利条件不变：仍然是最先清空手牌获胜。

### 基础参数修改入口

直接编辑 `assets/js/config.js`：

```js
match: {
  startingHandSize: 2, // 起手牌数
  aiThinkMs: 2000,    // AI 对手思考时间（毫秒）
  trusteeThinkMs: 900,// AI 托管思考时间（毫秒）
  fieldEveryRounds: 5,// 每几轮抽一次场地
  startingBalance: 2000
}
```

房间的 `baseBet`、`minBalance` 和 `ai` 难度参数也在同一文件中。

- 技能图标与名称/说明现在保持紧邻左侧，箭头独立贴右。
- 文案区域改为自适应伸缩并保留省略处理，移动端布局保持不变。

## V0.34 更新：对局界面精简

- 对局界面不再显示 AI 性格标签。
- AI 的个性参数、出牌倾向、目标选择与房间难度逻辑全部保留，仅隐藏性格名称展示。
- 顶部仍显示当前房间的 AI 难度，便于区分休闲 / 标准 / 高手。

## V0.33 更新：AI 性格标签显示修复

- 修复对局界面 AI 性格标签被头像右侧窄元数据区域裁切的问题。
- 性格标签改为玩家卡片独立信息行，不再与技能标签争夺宽度。
- 手机和横屏低高度布局也保留独立标签行。
- AI 个性与三档难度系统继续沿用 V0.32 的完整逻辑。

## V0.32 更新：AI 个性与难度

- 9 名 AI 对手拥有独立性格：稳健经营、疾风快攻、守势控场、冒险豪赌、技能经营、终结猎手、精算布局、爆发猛攻、诡谋牵制。
- 性格会影响大牌偏好、主动性、资源保留、技能使用、目标压制和终局追击。
- 三个房间加入不同 AI 强度：新手场为**休闲**，普通场为**标准**，高级场为**高手**。
- AI 性格会在后台影响决策；对局界面不显示性格名称，顶部房间标记仅显示当前 AI 难度。
- 开局日志记录本局 3 名随机对手及其性格。
- 旧存档导入时会自动补齐 AI 性格与当前房间难度配置。

## 主要内容

- 1 人 VS 3 AI，随机抽取 3 名不重复对手。
- 10 个技能、8 个场地事件、3 个房间档位。
- 支持单牌、对子、三带一、四条、葫芦、顺子、连对。
- 星石经济、音效与视觉反馈、管理员调试工具。
- 支持存档码导入 / 导出。

## 运行

```bash
npx serve .
```

也可以使用其他静态文件服务器。

## 验证

```bash
node --check assets/js/version.js
node --check assets/js/config.js
node --check assets/js/loader.js
node --check assets/js/game.js
```

## 目录

```text
index.html                  页面结构
assets/js/version.js        唯一游戏版本号
assets/js/config.js         基础对局与房间配置
assets/js/loader.js         启动资源加载
assets/js/game.js           规则、AI、渲染、音效和管理工具
assets/css/game.css         界面样式与动画
assets/icons/               《星局》品牌、房间与功能入口图标
assets/avatars/             玩家与 AI 头像
```
